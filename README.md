# 🗄️ MySQL Data Cleaning & Exploration Project

## 📊 Overview
This project demonstrates **data cleaning and exploratory analysis** using **MySQL Workbench**.  
The dataset used is the **World Layoffs Dataset (Kaggle)**, which contained inconsistencies, duplicates, missing values, and irrelevant fields.  
Through SQL queries, the dataset was transformed into a clean, reliable format ready for analysis and visualization.

---

## 🔧 Key Tasks
- **Data Cleaning**
  - Removed duplicates using `ROW_NUMBER()` and filtering logic.
  - Standardized date formats and normalized text fields.
  - Handled NULL values with defaults or row removal.
  - Dropped irrelevant columns to streamline usability.
  - Resolved safe update errors with proper configurations.

- **Exploratory Data Analysis (EDA)**
  - Identified trends in layoffs by company, industry, and country.
  - Analyzed time‑based patterns using cleaned date fields.
  - Created summary statistics and grouped insights for visualization.
